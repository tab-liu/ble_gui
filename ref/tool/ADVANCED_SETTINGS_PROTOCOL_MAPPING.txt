BLUETTI Device Studio V1.0.20 - 高级设置协议映射
============================================================

母版本：BLUETTI Device Studio V1.0 正式发布版增量开发链；本版由 V1.0.19 -> V1.0.20 修正

1. 恢复出厂设置
   2206 SetResetFactory
   写入值：当前 2218 SetArea 返回的地区代码 1..15。
   UI：危险操作卡片 + 二次确认；2206 为动作型寄存器，收到 06 正常回显后即认为指令已提交，设备可能重启。

2. 最大充电电流（本机当前实际使用）
   2214 SetGridMaxCurrent
   单位：1A
   说明：协议表中 2212 SetChgMaxCurrent 与 2214 SetGridMaxCurrent 都与充电电流相关，但当前产品不使用 2212；本机实际设置使用 2214，因此上位机将 2214 作为“最大充电电流”。
   约束：不得大于 2272 SetGridMaxCurrent_in 当前设定值。

3. 逆变电压选择
   2209 SetInvVoltage
   0：100V低压 / 220V高压
   1：120V低压 / 230V高压
   2：208V低压 / 240V高压

4. 逆变频率选择
   2210 SetInvFreq
   0：50Hz
   1：60Hz

5. 电网增强模式
   2225 SetGridPlusMode
   0：关闭
   1：开启

6. 最大电网输入电流（每相）
   2272 SetGridMaxCurrent_in
   单位：1A
   约束：不能设置为小于当前 2214 最大充电电流的值。

7. 系统记忆开关
   2226 SavePowerOutputState
   0：不记录
   1：记录 AC/DC 输出状态

辅助只读：
   2218 SetArea：用于显示当前地区并为恢复出厂设置提供地区代码。

高级设置页面轮询：
   2209~2210 -> 2214 -> 2218 -> 2225~2226 -> 2272
   分组轮询，避免一次跨大地址范围读取。

写入策略：
   普通设置：06 写单寄存器 -> 约300ms -> 03 回读同地址 -> 一致后UI确认。
   恢复出厂：06 写 2206 -> 校验正常回显；不强制回读，因为设备可能立即恢复/重启。
