BLUETTI Device Studio V1.0.20 Advanced Current Fix Test
========================================================

母版本
------
继续以 V1.0 正式发布版为唯一开发母版；本版在 V1.0.19 Fix Test 上做增量修正。

本版修正
--------
1. 修正高级设置“最大充电电流”使用的寄存器：
   - 旧实现：2212 SetChgMaxCurrent。
   - 当前产品实际使用：2214 SetGridMaxCurrent。
   - V1.0.20 已停止读取/写入 2212；高级设置页面“最大充电电流”改为读取/写入 2214。
2. 最大电网输入电流仍使用：
   - 2272 SetGridMaxCurrent_in。
3. 约束保持不变：
   - 2214 最大充电电流 <= 2272 最大电网输入电流。
   - 若降低 2272 后会小于当前 2214，UI 会阻止写入并要求先降低最大充电电流。
4. 滑块交互继续沿用 V1.0.19：
   - 设备回读值与 UI 待设置值分离。
   - 拖动/手工输入不会被后台轮询反弹覆盖。
   - 点击“应用”后写寄存器并回读确认。
5. 其它高级设置、Battery/PACK、故障、Settings、OTA、BLE 加密逻辑保持不变。

高级设置关键寄存器
------------------
2206 恢复出厂
2209 逆变电压
2210 逆变频率
2214 最大充电电流（本产品实际使用）
2218 地区
2225 电网增强模式
2226 系统记忆开关
2272 最大电网输入电流（每相）

注意
----
协议表仍存在 2212 SetChgMaxCurrent，但当前产品不使用该项。本测试版以实机定义为准，使用 2214。
