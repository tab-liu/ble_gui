ESP32S3_USB逻辑模块已上传，路径：https://192.168.102.10/svn/TecCenter/ComGroup/技术文件/通讯软件模块化/ESP32S3_USB模块，具体接口可参考“usb_host”文件夹内各个H文件，调用位置可参考模块化工程。
当前主要功能：
1.支持USB_CDC_MODEM功能（当前适配4G模块有：NL668-AM-10，NL668-CN，L610-EU，支持自动识别）
2.支持USB_HID标准设备（适配常见鼠标键盘，支持自动识别）


1.将文件夹“usb_host”、“espressif__iot_usbh_cdc”及“espressif__iot_usbh_modem”移植到你的main文件夹或者components文件夹下；

2.检查文件idf_component.yml
  # espressif/iot_usbh_modem: ^1.2.0
  # espressif/iot_usbh_cdc: ^2.0.1
  usb_host_hid: "^1.0.1"
【注意，不要引用“espressif/iot_usbh_cdc: ^2.0.1”及“espressif/iot_usbh_modem: ^1.2.0”，会覆盖掉本地适配的文件】

3.sdkconfig内修改参考SVN模块化框架
主要修改点：
#
# IoT USB Host Modem
#
CONFIG_MODEM_TARGET_USER=y
# CONFIG_MODEM_TARGET_NT26 is not set
# CONFIG_MODEM_TARGET_ML302_DNLM is not set
# CONFIG_MODEM_TARGET_AIR780_E is not set
# CONFIG_MODEM_TARGET_EC600N_CNLC_N06 is not set
# CONFIG_MODEM_TARGET_BG96_MA is not set
# CONFIG_MODEM_TARGET_MC610_EU is not set
# CONFIG_MODEM_TARGET_EC20_CE is not set
# CONFIG_MODEM_TARGET_EG25_GL is not set
# CONFIG_MODEM_TARGET_YM310_X09 is not set
# CONFIG_MODEM_TARGET_SIM7600E is not set
# CONFIG_MODEM_TARGET_A7670E is not set
# CONFIG_MODEM_TARGET_SIM7070G is not set
# CONFIG_MODEM_TARGET_SIM7080 is not set
CONFIG_MODEM_TARGET_NAME="User Defined"
CONFIG_MODEM_SUPPORT_SECONDARY_AT_PORT=y

#
# USB CDC interface config
#
CONFIG_MODEM_USB_ITF=0x1
CONFIG_MODEM_USB_ITF2=0x2
# end of USB CDC interface config

CONFIG_MODEM_DIAL_RETRY_TIMES=5
CONFIG_MODEM_PPP_APN="UNINET"
CONFIG_MODEM_SIM_PIN_PWD="1234"
# CONFIG_MODEM_PRINT_DEVICE_DESCRIPTOR is not set

#
# GPIO Config
#
CONFIG_MODEM_POWER_GPIO=0
CONFIG_MODEM_RESET_GPIO=0
CONFIG_MODEM_POWER_GPIO_INACTIVE_LEVEL=0
CONFIG_MODEM_RESET_GPIO_INACTIVE_LEVEL=0
# end of GPIO Config

#
# Timeout Config
#
CONFIG_MODEM_COMMAND_TIMEOUT_DEFAULT=2000
CONFIG_MODEM_COMMAND_TIMEOUT_OPERATOR=6000
CONFIG_MODEM_COMMAND_TIMEOUT_RESET=6000
CONFIG_MODEM_COMMAND_TIMEOUT_MODE_CHANGE=10000
CONFIG_MODEM_COMMAND_TIMEOUT_POWEROFF=1000
# end of Timeout Config
# end of IoT USB Host Modem

#
# IoT USB Host CDC
#
CONFIG_USBH_TASK_CORE_ID=0
CONFIG_USBH_TASK_BASE_PRIORITY=5
CONFIG_CONTROL_TRANSFER_BUFFER_SIZE=512
CONFIG_IN_TRANSFER_BUFFER_SIZE=1024
CONFIG_OUT_TRANSFER_BUFFER_SIZE=1024
CONFIG_DEVICE_ADDRESS_LIST_NUM=10
# end of IoT USB Host CDC
