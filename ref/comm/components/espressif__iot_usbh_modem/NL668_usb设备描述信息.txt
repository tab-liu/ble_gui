NL668 USB CDC接口说明
NL668 典型的 USB CDC 接口分配如下（以常见Quectel文档为例）：

Interface 0：通常为诊断口（DIAG）
Interface 1：通常为主 AT 口（AT，AT Only）
Interface 2：通常为 NMEA（GPS 数据）
Interface 3：通常为 PPP/Data
Interface 4：通常为辅助 AT 口（Secondary AT）
Interface 5：其他功能口
